# Tài nguyên đóng gói

- `fonts/BeVietnamPro-*.ttf` — Be Vietnam Pro (github.com/google/fonts, ofl/bevietnampro), giấy phép SIL OFL 1.1 (`fonts/OFL.txt`). Font phụ đề (FFmpeg `fontsdir`).
- `vi_words.txt` — các từ nhiều âm tiết lấy từ `Viet22K.txt` của github.com/vntk/dictionary (MIT, © 2017 VNTK). Dùng để không ngắt dòng phụ đề giữa 1 từ ghép.
